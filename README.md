# Moo Moo Madness

### Features

- Third-person combat for up to 2 players
- A map filled with filled destructible objects
- Dynamic scoring system
- Built in Unreal Engine 5.3

### Goals

This project was created to:
- Build experience with multiplayer design and development
- Strengthen my skills in networking logic and implementation
